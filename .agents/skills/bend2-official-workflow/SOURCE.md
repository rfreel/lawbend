# Source provenance

This repo-local skill is a concise adaptation of the Bend 2 agent guidance published at:

- https://bend2.dev/
- https://bend2.dev/notes/ai-agents-bend/
- https://bend2.dev/llms.txt

Key upstream guidance incorporated here:
- inspect `bend --version` and the complete `bend guide` before editing;
- keep laws as human-owned requirements and proofs separate;
- never weaken a law merely to make a proof pass;
- run `bend PROOF.bend` before claiming the requirements hold;
- test changed entry points and the actual deployment target;
- report commands, outputs, compiler version, and open holes;
- use bend2.dev examples as supporting material while treating the installed guide as
  the language-version authority.
