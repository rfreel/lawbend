# External observations

No observation has been made by the initializer. Do not create a successful report merely to make a check green.

A real observations.json must identify the task/contract revision, artifact ID and revision, observer identity, report ID, criterion coverage, observed values, defects, observation time and evidence location. Separate readback from independent judgment. Missing access is unavailable evidence, not evidence of failure. Keep counterevidence.

The receipt mechanism only records provenance and execution; it cannot determine whether an observer is independent or correct.
